# TodoPilot 1.0.0 candidate notes

TodoPilot is the renamed Windows release of Life Manager. It adds the white orbit icon on black, an interactive color wheel for separate light and dark palettes, validated JSON presets, a Contributors page, and native widget background opacity, a right-click menu, flexible sizing, and layout locking. Existing tasks, settings, and backups remain under `%APPDATA%\Life Manager`; the installer retains its prior AppId and install directory for an upgrade path.

The package includes the Flutter runtime and native widget. The installer is unsigned. Windows 10, installed upgrades and uninstall, widget alpha against different wallpapers, Win+D, multiple monitors and DPI, privacy integration, and complete native GUI interactions still require manual acceptance. Public release also awaits creator approval of the proposed MIT license and GitHub destination.
