# Todorbit 1.0.19-beta.5 - clearer UI on Windows and Android

- Clearer page, section and item titles, with quieter descriptions and metadata.
- Consistent typography, readable text contrast and palette-aware surfaces in
  light, dark and customized themes.
- Sync conflict review leads with changed values. Compare devices side by side
  on Windows or in a stacked phone layout. Complete records and previous values
  remain available; selected choices and Apply Selected are easy to locate.
- Large-text and short-window conflict dialogs keep their title scrollable
  so choices stay reachable, with Apply Selected fixed below.
- Visible deletion/related-record notices preserve the existing review rules.
- Shorter backup, sync setup and update copy, clear inline states and prominent
  recovery guidance. Core backup actions take priority over account maintenance.
- Keep the focused recovery input visible as the Android keyboard opens,
  including large text and resized windows.
- Group restore warnings and recovery steps; disclose profile IDs, paths and
  replaced settings on demand without changing replacement approval.
- Scrollable goal adjustments, milestones and habit value entry; improved task,
  navigation, template and report text hierarchy.

Windows x64 Setup and portable ZIP; Android ARM64, x86-64 and universal APKs.
Android versionCode 28, existing production signing identity. Schema stays 26;
existing tasks, preferences, profiles, backups and widget configurations remain.

This is an experimental pre-release. Real Google Drive pairing and sync exchange
have not passed real-account end-to-end acceptance; mocked checks are not that
acceptance. Background delivery depends on OS scheduling and authorization.
Snapshot backups remain independent and full restore requires restart.
Keep recovery codes/passphrases private and store a recoverable backup.
Windows app/setup remain unsigned. Physical device/OEM, Windows 10 and physical
Windows shell/DPI/input observations retain their documented limitations.
