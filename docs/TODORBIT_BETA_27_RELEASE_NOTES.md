# Todorbit 1.0.19-beta.27

Experimental beta for Windows x64 and Android. Build 50 uses SQLite Schema 29.

- Redesigned Today, Inbox, task lists, Calendar, and task and event editors.
  Planned days and deadlines stay distinct. Larger text and narrow layouts
  keep editing actions reachable.
- Refined Focus, Habits, Goals, Settings, Sync, Shared Files and Archive/Trash.
  The Windows and Android widgets use the Todorbit palette.
- Appearance keeps light and dark palettes, custom colors, text scale and
  layout choices. Windows remembers the preferred editor width on this device.
- Android launches with the neutral Todorbit background and a crisp orbit
  mark. The launch screen dismisses through the platform's normal first-frame
  handoff.

Keep a verified backup before updating. Use Windows Setup for an installed
copy or the portable ZIP for a portable copy. On Android use the GitHub APK
for your device architecture, with the same signing identity as the previous
GitHub beta. Verify the published SHA-256 for each download.

Start with a task edit and a Calendar event at enlarged text. Then check
timer resume, the home-screen widget and your saved appearance preferences.
Registered installer/update interaction, assistive output and real two-client
Drive recovery have separate manual acceptance steps.
