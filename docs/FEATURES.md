# Todorbit feature catalogue

[Documentation index](README.md) · [Platform support](PLATFORM_SUPPORT.md) ·
[Install Todorbit](INSTALLATION.md)

This catalogue describes [Experimental Beta 30](https://github.com/2HIK4/Todorbit/releases/tag/v1.0.19-beta.30)
(`1.0.19-beta.30+53`, SQLite schema 29), built from
[commit `253f4ed`](https://github.com/2HIK4/Todorbit/tree/253f4ed560018bfbb9acc9f1e110c823c77041d1). The default branch contains
an earlier application snapshot alongside the public documentation. The source
and test links below are pinned to the release commit.

## How to read the catalogue

- The 53 end-user capabilities are grouped into 15 areas. Related controls,
  modes, and interactions stay in the same capability. F54 records developer
  tooling separately.
- **Released in Experimental** means the linked source implements the
  capability in Beta 30. The platform and limitations apply to this prerelease.
  Optional Drive features require an enabled build and an authorized account.
- **Tests** identify automated coverage. The [verification record](https://github.com/2HIK4/Todorbit/blob/60a6fd6efa724d6541f3e847d1525ecfa78adaf7/docs/TODORBIT_BETA_30_CANDIDATE.md)
  reports checks executed on the release commit. See the runtime section for
  which journeys have manual or installed-app evidence.
