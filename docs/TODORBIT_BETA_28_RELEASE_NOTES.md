# Todorbit 1.0.19-beta.28

Experimental beta for Windows x64 and Android, build 51. Uses SQLite Schema 29.

- Graphite Neutral Silver is the default dark accent. Violet, Sage, Amber,
  Beta 27 Teal and Dusk remain available. Saved palettes and density preferences
  retain their values. To use Silver, choose it in Customize Theme → Dark →
  Dark palette preset and save.
- Windows task lists are wider and align with navigation. Upcoming groups
  scheduled tasks by day and gives deadlines their own visible label.
- Calendar uses a quieter mode control and a shorter compact Android header.
  Batched grid painting improved dense Day scrolling in the paired Windows
  Profile run. Some raster frames still miss the display budget and measured
  mode-switch latency varies.
- In-place updates preserve the existing profile. Export a verified backup
  before updating. Use the installer for an installed Windows copy, the ZIP
  for a portable copy, or the production-signed APK on Android.
