# Todorbit 1.0.19-beta.26

This experimental beta includes the integrated task editor and settings UI.
Desktop task rows distinguish running and paused timers, and starting a timer
keeps the task's status independent of the timer.

Windows users can use the setup executable for an existing installed copy or
extract the portable ZIP for a portable copy. On Android, use the signed APK
for your device architecture and install over the previous Todorbit version.
Verify the download against the published SHA-256 before installation.

The database schema remains at 29. Keep a recent backup before upgrading and
retain the previous installation until you have verified your own data.
