# Product

Life Manager organizes tasks, schedules, projects, habits, goals, and work time locally on Windows. It remains useful offline without accounts or cloud services. Windows is the initial target; Android and synchronization are future work.

## Core rules

- A task needs only a title. Category and project are optional; subtasks are one level deep.
- Scheduled work and actual deadlines are distinct. Missing planned work never completes or cancels a task.
- Completion, cancellation, archive, and deletion are deliberate actions. Deleted records eventually use recoverable Trash.
- Fixed events, locked work, dependencies, availability, and deadlines constrain scheduling suggestions. Bulk changes require preview and approval.
- Actual time, planned sessions, and task completion remain independent.
- All statistics derive from stored data. Reminders are off unless enabled.
- Desktop widget attachment and `Win + D` behavior require real Windows verification before claiming support.

## Foundation acceptance

Launch locally on Windows; create and edit categories, projects, and tasks; view Today, Inbox, Upcoming, Overdue, Waiting, Completed and project views; complete, reopen, and delete tasks; persist changes across restarts; switch light/dark theme; pass analysis, tests, and a Windows build. More complete acceptance is staged in `ROADMAP.md`.
