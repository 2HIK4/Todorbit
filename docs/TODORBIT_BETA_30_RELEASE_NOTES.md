# Todorbit v1.0.19-beta.30 (`1.0.19-beta.30+53`)

Experimental prerelease targeting `feature/todorbit-beta27-refinement`, SQLite schema `29`. Previous experimental version: `v1.0.19-beta.29` (`52`). Sync protocol, local SQLite schema, backups, themes, and hotkeys remain compatible across upgrade; `Stable` and `main` remain untouched.

## Summary of Changes

- **Windows Native Desktop Widgets (`TodorbitWidget.exe`)**: Replaces the white 4-way text outline halo with a restrained directional contrast lift (`WidgetText.cs`) and aligns `"taskRow"` underlay contrast composition with `"content"` / `palette.Row`, fixes translucent Light/Dark surface mutation and opaque hover blends (`WidgetSurfaces.cs`), implements smooth 16 ms eased pixel scrolling across Tasks and Calendar widgets via shared `WidgetScrollAxis` honoring OS `MouseWheelScrollLines` and reduced-motion preferences (`idle_paints_250ms = 0`, `WmDestroy` timer/popup cleanup, `DateToday` / midnight scroll reset), and fixes Calendar agenda viewport bottom clipping.
- **Embedded Settings > Hotkeys (`HotkeysEditorView`)**: Moves the complete Hotkeys editor inline into Settings (live search, key-combination capture, conflict warnings, preset Save / Duplicate / Rename / Delete, `Reset all`, Calendar shortcuts legend) while preserving standalone `HotkeysDialog`, `Tab`/`Escape` and keyboard `Save`/`Cancel` focus behavior, bare-modifier handling, and `720×680 @ 1.5x` responsive stacking.
- **Data Safety, Search & Cross-Platform Reliability (Reconciled from PR #3)**: Preserves fresh automatic snapshots after device clock rollbacks (`BackupService`), restarts damaged full-length partial updater downloads cleanly with RFC 9110 case-insensitive `Content-Encoding` checks (`ResumableUpdateDownload`), includes non-cancelled fixed events in desktop sidebar search (`Workspace`), trims mobile task/event/location queries and preserves `48 dp` touch targets (`MobileWorkspace`), and enforces architecture boundary checks (`tools/test_architecture_boundaries.py`).
- **Developer Automation & Documentation (`TDAT`)**: Hardens `Invoke-BoundedProcess` stdin closure + bounded pipe drain, working-tree scope-signature `-Resume` checkpoints (`verify.ps1`, `dev.ps1`), bounded `adb` runtime diagnostics with persistent blocker receipts (`Runtime.psm1`), portable worktree path checks (`Doctor.psm1`, `tools/test_workspace_paths.py`), and `tools/test_public_readiness_hygiene.py`.
- **Upgrades & Data Safety**: Schema 29 compatible with Beta 29 (`52`). Export a verified backup before updating. Use the setup installer for an installed Windows copy, the portable ZIP for a portable copy, or the production-signed APK matching your ABI on Android, and verify published SHA-256 checksums.
