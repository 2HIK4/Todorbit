# Todorbit 1.0.16 — Calendar refinements and optional support

Windows x64 **pre-release**. Requires Windows 10 or Windows 11.

- One Calendar widget: rounded date cells, clear today/selection states and a
  dedicated selected-day agenda. Old presentation settings load compatibly.
- All selected-day tasks/events remain in one scrollable agenda. Paging arrows
  are removed; extra height expands the agenda instead of stretching date cells.
- Nearby Tasks/Calendar widget edges snap during resizing and dragging. Exact
  same-DPI bounds persist; Lock Layout and independent widget settings remain.
- Subtle scroll-edge fades improve Settings, theme and widget customization.
- Cleaner widget menus retain the normal task-entry bar and shortcuts.
- Optional Support Todorbit popup opens the maintainer's PayPal.Me page:
  **https://paypal.me/2hussam4**. A brief one-time header highlight respects
  reduced motion. Todorbit remains free; no payment data is collected in-app.
- UI UX Pro Max-assisted polish improves select focus and custom-accent/error
  contrast while preserving Todorbit's lavender identity and customization.

The support destination is fixed in official source, never imported from themes
or settings. Forks can modify source; official packages come from `2HIK4/Todorbit`.
Packages are unsigned. Verify the published SHA-256 values before manual install.
The experimental Google Drive backup configuration is retained from v1.0.15;
existing experimental and unsigned-release limitations still apply.

Physical mouse input, snapping feel, DPI/multiple monitors, Win+D, Explorer
restart, screen readers and registered installer execution remain unverified.
Please test those on your Windows PC; automated tests are not physical acceptance.

To upgrade, open **Settings > Software Updates**, choose **Pre-release**, then
**Check for Updates**, **Download update**, and **Update and Restart**. Create a
verified backup first. Portable users should retain the same application path.
